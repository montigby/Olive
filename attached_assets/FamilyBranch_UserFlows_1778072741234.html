UF-05
Error States Reference
All error conditions across UF-01–04. Every error must have a recovery path. No dead ends.
UF-05 · Error State Catalogue
Error IDFlowTriggerMessage to UserRecovery PathSeverity
E-01 UF-01 Step 2 Email already registered "An account with this email already exists." Inline error under email field. Show "Sign In instead" link. Medium
E-02 UF-01 Step 2 Password too weak "Password must be at least 8 characters." Inline strength indicator under field. Block submit until met. Low
E-03 UF-01 Step 4 No members added "You haven't added any family members yet. Continue anyway?" Confirmation modal. Yes → proceed. No → return to add members. Low
E-04 UF-02 Step 1 Invite token expired "This invite link has expired. Links are valid for 30 days." Show family admin contact suggestion. No further action possible on this link. High
E-05 UF-02 Step 1 Invite token already used "This invite link has already been used." If user has an account, offer Sign In. Otherwise contact family admin. High
E-06 UF-02 Step 3 Email already linked to different person record "This email is already linked to a different profile." Offer to sign in to existing account and re-link, or use different email. Flag for manual review if needed. High
E-07 UF-03 Step 2 Parent family not found in search "No family found with that name." Suggest: "Ask your family admin to share their unit code directly." Medium
E-08 UF-03 Step 5 Duplicate pending link request "You already have a pending request to this family." Show current request status and date sent. Offer to cancel and resend. Low
E-09 UF-04 Step 4 Network error on save "Could not save. Please check your connection and try again." Retry button. Keep changes in local state. Do not lose edits. Medium
E-10 All flows Session expired mid-flow "Your session has expired. Please sign in again." Redirect to sign-in. Preserve deep-link return URL so user lands back where they were. Medium
